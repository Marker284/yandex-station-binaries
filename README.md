# Yandex Station Binaries

Готовые скомпилированные бинарники, сервисные утилиты, пакеты и архивы для проекта [Yandex Station Extended](https://github.com/Marker284/yandex-station-extended) ([hackalice.me](https://hackalice.me)).

## Структура

* `bin/` — автономные статические бинарники под архитектуры `aarch64` / `armhf` (`dropbear`, `fastfetch`, `nano`, `zsh`, `bt-proxy`, `yse` и др.).
* `packages/` — архивы установки компонентов и пакеты (`mini2-ssh.tar.gz`, `airplay-lite2-armhf.tar.gz`, `Station1_ROOT.zip`, `librespot-micro-installer.zip`, сервисные сертификаты и медиа).
* `tuvio/` — сервисные архивы для телевизоров Tuvio.
